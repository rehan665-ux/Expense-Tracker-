# Expense Tracker

A simple **Expense Tracker** made with Python.
This program allows you to add expenses, view saved expenses, and calculate the total amount spent.

## Features

* Add a new expense
* Show all stored expenses
* Calculate total expenses
* Exit the program
* Simple and beginner-friendly menu

## How It Works

When you run the program, you will see a menu:

```text
1. Add Expense
2. Show Expenses
3. Total Expense
4. Exit
```

### 1. Add Expense

Enter the name of the item and its price.

Example:

```text
Enter item: Burger
Enter price: 250
Expense added successfully!
```

### 2. Show Expenses

This option displays all the expenses you have added.

Example:

```text
--- Stored Expenses ---
Item: Burger
Price: 250.0
----------------
Item: Juice
Price: 100.0
----------------
```

### 3. Total Expense

This option calculates the total amount of all stored expenses.

Example:

```text
Total Expense: 350.0
```

### 4. Exit

This option closes the program.

```text
^^^^^|||Thanks for using our Expense Tracker|||^^^^^ !
```
